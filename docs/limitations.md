# 已知限制与建议

> 来源:插件功能开发完成后的全面审查(2026-09)。多数为**非阻塞**项,记录在此供后续迭代参考。

## 已知限制

1. **popup 每次打开拉取全量书签做 URL 查重**。书签量在几百条以内无感;上千条后 popup 打开会变慢,届时应改为后端提供按 URL 查重接口,只查一条而不是全量。
2. **右键菜单收藏无法选择分类/私密/标签**(默认公开、未分类)。这是刻意的“最快路径”设计;如需更完整的右键收藏,可考虑右键时弹出一个轻量确认面板。
3. **AI 按钮基于 `/api/public/ai-config` 的 `aiEnabled` 显示**。若后台配置了 AI 但关闭了「自动填充」特性开关,按钮仍会显示但点击报错——可进一步用更细粒度的特性开关控制按钮显隐。
4. **CORS 白名单只认扩展 origin**(`chrome-extension://` / `moz-extension://` / `safari-web-extension://`),插件必须通过 options 页申请站点 host 权限才能跨域;这是 MV3 的安全模型,属预期行为,但首次配置的“先授权再验证”顺序如果被改乱会导致“无法连接站点”。
5. **插件构建产物未上架应用商店**。当前通过 `chrome://extensions` 加载已解压扩展;正式分发需打包 zip 上架 Chrome Web Store / Firefox AMO,并准备隐私政策页。

## 遗留建议

- **提交 git**:Phase 0(令牌基建)与 Phase 1(插件)的改动尚未提交,建议按两个 commit 提交,便于回滚与协作。
- **完善 README/文档**:详细文档已迁移到 `docs/`(见 [README.md](./README.md)),根 README 仅保留入口。
- **正式发布前**:补齐隐私政策页(如实说明只把 URL/标题传输到用户自己的服务器)、在 CWS 填写隐私声明。
- **令牌体验**:改密码会联动吊销插件令牌(安全设计),失效时插件会引导重新配置,符合“失效即明确告知 + 一键自愈”原则。
